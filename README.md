# 🎓 ระบบประเมินการเรียนการสอน (Teaching Assessment System)

เว็บแอปพลิเคชันสำหรับการประเมินการเรียนการสอนและประเมินทักษะนิสิต พัฒนาด้วย **Google Apps Script** ร่วมกับ **Tailwind CSS**, **SweetAlert2** และ **Chart.js** โดยใช้ **Google Sheets** เป็นฐานข้อมูลหลัก

---

## 📌 ฟีเจอร์หลักของระบบ

### สำหรับอาจารย์ (Teacher Role)
- **แดชบอร์ดสรุปผล:** แสดงตัวเลขสถิติภาพรวม กราฟสัดส่วนประเภทการประเมิน (Doughnut Chart) และกราฟแสดงนิสิตที่ได้รับการประเมินสูงสุด 10 อันดับแรก (Bar Chart)
- **ตัวกรองข้อมูล:** คัดกรองข้อมูลตามประเภทแบบประเมิน กลุ่มนิสิต หรือรายชื่อนิสิตได้
- **ขั้นตอนการทำแบบประเมิน (Multi-step Assessment):**
  - ขั้นที่ 1: เลือกกลุ่มและเลือกนิสิตที่ต้องการประเมิน (เลือกได้พร้อมกันหลายคน)
  - ขั้นที่ 2: เลือกแบบประเมิน (ระบบกรองเฉพาะแบบประเมินที่ตรงกับชั้นปีของนิสิตให้อัตโนมัติ)
  - ขั้นที่ 3: ตอบคำถามตามเกณฑ์การให้คะแนน (รองรับ Choice/Radio, Dropdown, Textarea)
  - ขั้นที่ 4: สรุปคะแนนรวมและบันทึกข้อมูลลงฐานข้อมูลพร้อมกันทุกคน
- **จัดการข้อมูลการประเมิน:** ค้นหา แก้ไขคะแนนย้อนหลัง หรือลบรายการประเมิน พร้อมระบบแบ่งหน้า (Pagination)

### สำหรับนิสิต (Student Role)
- **สรุปภาพรวม:** ดูจำนวนครั้งที่ได้รับการประเมินทั้งหมด และสถิติแยกตามหัวข้อ
- **ประวัติการประเมิน:** ตรวจสอบผลการประเมินย้อนหลัง พร้อมดูข้อเสนอแนะจากอาจารย์ผู้สอน
- **รายละเอียดแบบประเมิน:** ตรวจสอบเกณฑ์การให้คะแนนและหัวข้อประเมินเฉพาะชั้นปีของตนเอง

## 🗄️ โครงสร้างฐานข้อมูล Google Sheets

ในการใช้งาน ต้องสร้างแผ่นงาน (Sheet Tabs) ใน Google Sheets ให้ครบทั้ง 4 แท็บ และกำหนดชื่อหัวตารางในแถวแรก (Row 1) ให้ตรงตามนี้:

### 1. แผ่นงาน `Students`
เก็บข้อมูลนิสิต
| คอลัมน์ | คำอธิบาย | ตัวอย่างข้อมูล |
| :--- | :--- | :--- |
| `id` | รหัสนิสิต (ใช้เข้าสู่ระบบ) | `65010001` |
| `fullname` | ชื่อ-นามสกุล | `นายสมชาย ใจดี` |
| `password` | รหัสผ่านเข้าสู่ระบบ | `1234` |
| `group` | กลุ่มของนิสิต | `กลุ่ม 1` |
| `year` หรือ `ชั้นปี` | ชั้นปีของนิสิต | `4` |
| `picture` | ลิงก์รูปถ่าย (ถ้ามี) | `https://lh3.googleusercontent.com/...` |

### 2. แผ่นงาน `Teachers`
เก็บข้อมูลอาจารย์ผู้ประเมิน
| คอลัมน์ | คำอธิบาย | ตัวอย่างข้อมูล |
| :--- | :--- | :--- |
| `fullname` | ชื่อ-นามสกุลอาจารย์ | `อ.สมศักดิ์ รักสอน` |
| `email` | อีเมล (ใช้เป็น Username เข้าสู่ระบบ) | `teacher@example.com` |
| `password` | รหัสผ่านเข้าสู่ระบบ | `pass1234` |

### 3. แผ่นงาน `AssessmentTypes`
เก็บแบบประเมินและเกณฑ์คำถาม
| คอลัมน์ | คำอธิบาย | ตัวอย่างข้อมูล |
| :--- | :--- | :--- |
| `id` | รหัสแบบประเมิน | `T01` |
| `name` | ชื่อหัวข้อแบบประเมิน | `การซักประวัติและการตรวจร่างกาย` |
| `year` | ชั้นปีที่ใช้แบบประเมินนี้ (เว้นว่าง = ทุกชั้นปี) | `4` |
| `question` | โครงสร้างคำถามในรูปแบบ JSON string | `[{"id":"q1","text":"ความถูกต้อง","type":"radio","options":[{"text":"ดีมาก","value":5},{"text":"พอใช้","value":3}]}]` |

> **รูปแบบ JSON ในคอลัมน์ `question` รองรับ:**
> - `type: "radio"` สำหรับเกณฑ์ให้คะแนนตัวเลือก
> - `type: "select"` สำหรับดรอปดาวน์
> - `type: "textarea"` สำหรับช่องพิมพ์ข้อเสนอแนะเพิ่มเติม

### 4. แผ่นงาน `Assessments`
เก็บประวัติการทำแบบประเมินที่ถูกบันทึก
| คอลัมน์หลัก | คำอธิบาย |
| :--- | :--- |
| `id` | UUID ของรายการประเมิน (ระบบสร้างให้อัตโนมัติ) |
| `timestamp` | วันที่และเวลาที่บันทึก |
| `datetime_edit` | วันที่และเวลาที่มีการแก้ไขล่าสุด |
| `student_fullname` | ชื่อ-นามสกุลนิสิตที่ถูกประเมิน |
| `student_group` | กลุ่มของนิสิต |
| `teacher_name` | ชื่ออาจารย์ผู้ประเมิน |
| `assessment_name` | ชื่อแบบประเมิน |
| `q1`, `q2`, `q3`, ... | คะแนนหรือคำตอบตามลำดับข้อคำถาม |

## 🚀 ขั้นตอนการติดตั้งและการนำไปใช้งาน

1. สร้าง **Google Sheets** ขึ้นมาใหม่ 1 เล่ม แล้วสร้างชีตย่อยและหัวตารางตามโครงสร้างด้านบน
2. ไปที่เมนูด้านบนเลือก **ส่วนขยาย (Extensions)** > **Apps Script**
3. สร้างไฟล์ในโปรเจกต์ Apps Script:
   - ไฟล์สคริปต์: ตั้งชื่อว่า `Code.gs` แล้วนำโค้ดจาก `Code.gs` (หรือ `Code.js`) ไปวาง
   - ไฟล์ HTML: กดเครื่องหมาย `+` เลือก **HTML** ตั้งชื่อว่า `index.html` แล้วนำโค้ดจาก `index.html` ไปวาง
4. บันทึกโปรเจกต์ (Ctrl + S)
5. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน > **รายการทำให้ใช้งานได้ใหม่ (New deployment)**
6. คลิกรูปฟันเฟืองเลือกประเภทเป็น **เว็บแอป (Web app)**
   - **คำอธิบาย:** เวอร์ชันเริ่มต้น
   - **เรียกใช้ในฐานะ (Execute as):** ตัวฉัน (Me)
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
7. กด **ทำให้ใช้งานได้ (Deploy)** และอนุมัติสิทธิ์การเข้าถึงข้อมูล (Authorize Access)
8. คัดลอก **URL เว็บแอป (Web App URL)** ไปใช้งานเพื่อเปิดเข้าระบบ
